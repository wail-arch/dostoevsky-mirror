# Character Image Drop Folder

Drop approved or generated character imagery here.

Use one folder per V1 result-worthy character:

- `underground-man`
- `raskolnikov`
- `sonya-marmeladova`
- `svidrigailov`
- `prince-myshkin`
- `nastasya-filippovna`
- `rogozhin`
- `ivan-karamazov`
- `dmitri-karamazov`
- `alyosha-karamazov`
- `stavrogin`
- `kirillov`

Recommended filenames inside each character folder:

- `portrait.webp` or `portrait.png`
- `background.webp` or `background.png`
- `source.md`

For downloaded free-license/public-domain images, add `source.md` with:

- source URL
- creator/artist if known
- license
- attribution text
- whether commercial use is allowed

For GPT-generated images, add `source.md` with:

- generation tool
- prompt summary
- date generated
- note that it is original generated artwork for this project
